    Soundboard.Sounds.Uploads.CreateRequest (soundboard v1.7.0)

    Copy Markdown

    The input to create a sound, built from request params (new/2).

    A local file only comes in as a %Plug.Upload{}, the file Plug received in the request; any other file/upload param (such as a map naming a server path) is ignored, so a client can never make the server copy one of its own files. Callers that already hold a received file (the LiveView's consumed upload entry) attach it with put_upload/2.
